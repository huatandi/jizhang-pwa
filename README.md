# 飞常明细 · 智能记账系统（PWA 离线版）

复刻 Excel 明细表功能的智能记账系统（全球通用 · 多币种 · AI 识别 · 语音记账），打包为**完全离线的 PWA**，支持 iPhone / 安卓添加到主屏幕使用。

## ✨ 功能

- 📊 数据总览（KPI + ECharts 图表）
- 💰 收入 / 💸 支出 / 📦 进货 记账
- 📷 本地图片识别（PaddleOCR 主引擎 + Tesseract 兜底 + Document Intelligence V7：金额/日期/商户裁决、模板纠错学习、ROI 救援）
- 🎤 语音记账（多笔可编辑，保存前预览确认）
- 🔍 明细查询 + 全局搜索（关键词 + 金额区间）
- 📅 月度统计 + 同比环比报表
- 💱 多币种记账（MXN/CNY/USD + 汇率换算）
- 🏦 资产账户（期初余额 + 资产/负债/净资产）
- ⏰ 语音提醒（重复规则 + 稍后提醒 + 系统通知）
- ⛅ 天气预报（中文/西语/英语，降雨/大风时间、强度、持续时间、7天/逐小时预报）
- 📋 快捷模板一键复账
- 💾 数据备份导出

## 🚀 快速开始

1. 本仓库通过 **GitHub Pages** 部署，启用后访问：
   `https://<你的用户名>.github.io/<仓库名>/`
2. iPhone Safari 打开 → 登录（默认密码 `12345`）→ 分享 → **添加到主屏幕**
3. 完全离线可用，数据存手机本地

## 📦 部署

详见 `docs/PWA部署与iPhone测试指南.md` 或桌面版项目 `docs/` 目录。

## 🔧 重新打包

```bash
node server/scripts/package-pwa.js   # 生成 dist/jizhang-pwa-<日期>.zip
```

## ⚠️ 说明

- PWA 版为完整记账核心（含本地图片 OCR 识别 + 语音记账）
- 图片识别本地优先：PaddleOCR（PP-OCRv5）主识别，Tesseract 作为回退/局部救援；GitHub Pages 下 WASM 单线程速度受设备限制，已采用单次主 OCR + 关键字段 ROI 救援减少重复整图识别
- 数据在手机本地（IndexedDB），与桌面版相互独立
- 默认密码 `12345`，登录后建议立即修改
